# 动作卡模板

> **这是整套方法论里收益最大的东西。** 实测对照：任务书里有现成命令的子 agent **3 分钟开跑**；只有阅读清单的，开工税 **30~56 分钟**。
> **一张卡 = 一个「明确动作」**。
> **明确动作** = 已有命令/接口、判据可机械读取的动作。
>
> 文件命名建议：`动作卡/<链>-<节点>-<动作名>.md`（如 `动作卡/<业务链>-触发-单枚验命中.md`）

---

```yaml
动作: <动作名>
所属链: <链名>
节点: <节点 id>
适用: <什么情况下用这张卡>          # 一句话，帮 AI 认出"这就是我这次要做的"
禁区: <什么情况下不许用这张卡>        # 一句话，防止误用
```

## 1 动作（一条命令原文，照抄）

```powershell
<把那条命令原样写在这里，含所有参数与默认值>
```

> ⚠ **必须是一条能直接跑的命令**，不许写"参考某文档""按某规范执行"。
> ⚠ **必须含仓根**（先 `cd <仓根绝对路径>`，或写绝对路径）。
> 实测：同一批任务里，**"给了文件但没给仓根"导致子 agent 两次扑空、跑错目录**（见 `experiments/exp-001-brief-shape/成因核实.md`）。
> 若必须多步，按序编号，每步一条命令——**但优先把多步封装成一条命令**。

## 2 判据（怎么算做成了）

| 判据 | 读法 | 成功条件 |
|---|---|---|
| <判据名> | <库行 SQL / 回执字段 / 日志关键字> | <明确的值或条件> |

> **优先级写死**：**库行（走索引列） > 接口回执字段 > 链路节点日志**。
> **有库行判据可用的，禁用节点链**（实测：节点链每次 4~5 分钟，库行秒级）。

**一次执行只交一份 ≤25 行的回执行**（不是四份文书）：

```
动作：<命令>
关键回执：<字段=值>
结论：<一行>
清场：<一行，或"无需清场">
```

## 3 前置与清场

- **前置**：<需要先有什么；没有怎么办（另一张动作卡 / 升级路径）>
- **清场**：<跑完要删什么、要恢复什么>
- **共享资源**：<这个动作会写哪个可写单元？并发时必须认领它的 id>

## 4 常见坑（写实测过的，不写想象的）

| 现象 | 真因 | 怎么避 |
|---|---|---|
| <症状> | <真因> | <做法> |

> 原则：**能写成判定工具的纪律，就别只留在文本里。**
> （例：把"某参数用错会静默返回空"直接做成命令的主动提示，而不是指望 AI 记得读文档。）
