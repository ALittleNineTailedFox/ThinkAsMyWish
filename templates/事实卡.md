# 事实卡模板

> **一张卡 = 一条已定结论。** 专治实测最贵的失效：**结论已写在仓里，AI 却靠现场试错重新发明了一遍**（实测三处，合计代价：白跑 13 分钟 + 白跑一轮 + 试错 12 枚料）。
>
> 文件命名建议：`事实/<主题>-<结论短名>.md`，或一条一个文件。

---

```yaml
结论ID: <唯一 id，下游引用它>
一句话: <结论本身，可直接照着做>
权威源: <文件路径:行号 / 记录ID / 命令回执>     # 必填，无锚点的结论不得进任务书
定于: <日期> by <谁定的>
适用范围: <在什么条件下成立>
不适用: <什么条件下这条结论是错的>              # 必填，防止被过度泛化
状态: <有效 / 已作废（作废要写被谁取代）>
```

## 1 一句话结论

<用"照着做"的语气写。不要写分析过程。>

**反例**（实测的原文形态，AI 读到也不停手）：
> 「`decimalAttribute → null` ⇒ 参数无效分支」

**正例**：
> 「**某字段为空时该参数静默不生效；要让它生效，必须先注入该字段。**」

> 差别：反例是**实现细节**，AI 还得自己推一行才能用于停手；正例是**可直接照做的结论**。
> **判据：AI 读完这条，还需不需要自己补一个判断？需要就重写。**
