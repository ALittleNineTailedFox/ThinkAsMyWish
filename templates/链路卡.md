# 链路卡模板

> 一条链 = 一串**有序节点**。这是 AI 定位"我这次落在哪"的唯一锚点，其余上下文全部由它推导。
> 文件命名建议：`链路/<链名>.md`

---

```yaml
链名: <链名>
一句话: <这条链干什么>
入口: <从哪开始>
出口: <到哪算完>
```

## 1 节点表（**一行一节点**）

| # | 节点 id | 节点一句话 | 上游 | 下游 | 判据在哪读 | 详情指针 |
|---|---|---|---|---|---|---|
| 1 | | | — | | | |
| 2 | | | | | | |
| 3 | | | | | | |

**字段纪律**：
- **节点一句话**：给所有人看（这就是"读全"的部分——一行概览）。
- **判据在哪读**：必填。写"库行/回执字段/日志"，**不写"看代码"**。
- **详情指针**：**只给指针，不给正文**。AI 按自己落在哪个节点去取，取多少由它决定。

## 2 装载规则（谁该看哪一段）

> **读全 ≠ 全装。** 同一批文件，靠锚点切换装载面。

| 角色 | 装什么 | 不装什么 |
|---|---|---|
| **统筹者** | 全节点的「一句话」＋ 验收判据 | 具体实现细节 |
| **执行者（本节点）** | 本节点**完整卡** ＋ 上下游详情 | 无关节点的详情 |
| **只读探查** | 3 行：节点 id / 判据 / 是否命中人工闸 | 其余一切 |

## 3 常见走错的地方

| 走错 | 真相 | 依据 |
|---|---|---|
| <AI 容易认成 A> | <其实是 B> | <文件:行号> |

> 这一节专治"AI 自己推理出错误链路"。**每条必须带实锚**，否则不算。

## 4 边界（明确说出"不属于本链"）

- <某个容易混进来的东西> **不属于本链**，它在 <另一条链>。
- 边界之外的东西，**只要一行概览**，不要详情。
